Getting Started

Copy a world, run it, walk around in it.

A world is a file

Everything in your world — every room, object, character, and command — lives in one file. The program in moo/ is just the machinery that brings that file to life. Once you know this, the rest follows: to make a new world you copy the file. To back one up, you copy it again. To try something reckless, you copy it, wreck the copy, and delete it.

MegaMOO comes with mm.db: a small starter world with a lobby, a character generator, one room to stand in, and a wizard account. Copy it, then run the copy.

$ python3 megamoo.py mm.db mygame.db # make your own world $ ./mm mygame.db # run it

Now connect. Any MUD client will do, or plain telnet localhost 6770. Log in as wizard with the password megamoo, and you are standing in a world that is entirely yours.

Change this first

The wizard password is megamoo on every copy, and it is printed in this manual, so it is not a secret. Change it with setpass before anyone else can reach your world.

Copying, in a little more detail

Giving megamoo.py two names means "copy the first to the second." It makes the new world, tells you where it put it, and stops. It does not start the server — running the new world is the second command.

Name the copy carefully

The second name has to end in .db. Anything else is quietly read as something other than a filename, and no copy is made. A bare number is read as a port, so megamoo.py mm.db 7777 runs mm.db rather than copying it. And an existing file at the destination is overwritten without asking.

Running more than one world

Each world is a separate program with its own file, so you can run several at once and they cannot touch each other: the real one, a scratch copy you are about to ruin, and last week's backup for comparison. Start each the same way.

$ ./mm mygame.db & # the real one $ ./mm scratch.db & # somewhere to break things

You do not assign ports. The first world takes 6770, the next takes 6771, and each one says which it got when it starts. If you need a specific number — because you told people where to connect, or a firewall expects it — ask for it and you will get it or an error, never a silent move:

$ ./mm mygame.db 6777

What ./mm does for you

./mm is a convenience wrapper. Every run gets three things you would otherwise have to arrange yourself:

  • free ports, as above;
  • verb auto-reload, so editing a command's file changes the running game;
  • the tooling connection switched on, with a password kept in ~/.megamoo/token.

For a world with real players in it, python3 megamoo.py mygame.db runs the same server with none of the three — which is what you want once you are no longer editing it live.

Letting tools — and an AI assistant — into your world

Alongside the door players use, a world can open a second, private door for software. It is off unless you ask for it, it only accepts connections from your own machine, and it needs the password mentioned above. ./mm switches it on.

The reason to care is that an AI assistant can then work in your live world rather than guessing from files. It can look at what is actually on object #200, run a command as a test character and read what the game printed back, fix a command that just threw an error, and check the log. The edit–restart–reconnect–retype loop collapses into asking for the change and reading the result.

If you use Claude Code, connect it once and you are done:

$ claude mcp add megamoo -- python3 ~/megamoo/tools/megamoo_mcp.py

No port and no password in that line: it finds the running world by itself, and keeps working when the world restarts on a different port. With several worlds running, ask it which are up and which to work on — "what worlds are running?" and "work on scratch" are enough.

This door is wizard access

Anything coming through it can run any code against your world. Keep it on your own machine, do not share the token, and do not switch it on for a world strangers can reach. If you are letting an assistant work, confirm which world it is pointed at before you let it write anything — "scratch" and "the real one" are one word apart.
