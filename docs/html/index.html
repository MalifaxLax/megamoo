MegaMOO

A persistent, multiplayer, fully programmable text world — where the in-world language is Python itself.

Python 3 · asyncio zero dependencies SQLite persistence Telnet + WebSocket

MegaMOO is a scratch-built server in the tradition of LambdaMOO: a single long-running process that holds a living world of numbered objects — rooms, items, characters, exits — in a persistent SQLite database, and lets many players connect to it at once over plain Telnet or WebSocket. It keeps the ideas that made MOO worth copying — objects addressed by number, single-parent prototype inheritance, a natural-language command parser, and the ability to write and rewrite the world's behaviour from inside the world while it runs — but it is an original implementation on asyncio with no third-party dependencies, not a line-by-line port of the C original. The one change that matters most: where a classic MOO makes you program in a purpose-built MOO language, every MegaMOO verb — from look to @dig — is an ordinary Python file with the full standard library available, executed live against the object database. There is no DSL to learn and no build step; you edit a verb and the next player to type the command runs your new code.
