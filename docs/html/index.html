MegaMOO

Build a text world that people can log into — and change it while they are still inside it.

runs on one machine no setup to speak of write it in Python

A MegaMOO world is a place made of words. Rooms, doors, people, and objects live in a single file on your computer; you run one program, and anyone you give the address to can telnet in and walk around. It is the same kind of world as LambdaMOO — the text worlds people have been building since the eighties.

What makes it worth your time is that the world is editable from inside. You do not stop the server, change a file, and start it again. You dig a room while standing next to where it should go. You rewrite what a door does, and the next person to open it gets your new door. Every command in the game — from look to @dig — is a short Python file you can read and change, and you do not need to be a programmer to change one.
