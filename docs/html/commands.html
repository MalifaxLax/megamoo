05 · Command Reference

Every staff command, grouped by what it is for.

Every character inherits all of these. The Auth column is the level you need — see Who Can Do What. Without it, the command answers "Do what?" and does nothing.

Building the world

CommandAuthDoes
@dig[/types|/tel] <roomtype> [= <name>]gm2Create a room. /types lists room types, /tel teleports you there.
@make <parent> = <name> [with <owner>]gm3Create an object as a child of a prototype. /drop leaves it in the room instead of your inventory.
@delete <object>gm2Recycle an object.
@move <object> to <dest> [with <msg>]gm2Relocate an object.
@parent <object> = <new parent>gm3Reparent, changing what it inherits.
@renumber <object> to <n>gm5Change an object's number.
@list [<start>] [to <end>]gm3List objects in a number range.

Exits

CommandAuthDoes
@open <direction> [to <dest>]gm2Directional exit (north, south, …).
@vopen <direction> to <dest>gm2Virtual directional exit — no object created.
@gopen <name> [to <dest>]gm2Walkable named exit (a gate, an arch).
@dopen <name> to <dest>gm2Door — a closable exit.
@copen <name> [to <dest>]gm2Climbable exit (stairs, a ladder).
@jopen <name> [to <dest>]gm2Jumpable exit (a chasm).
@rmexit <exit>gm2Remove an exit.
@virtualize <exit>gm2Convert an object exit into a virtual one.

All the @*open commands accept /noret to create a one-way exit with no return path.

CommandAuthDoes

@desc <object> = <text>gm2Set the description.
@article <object> = <a|an|the>gm2name_mod_list slot 0.
@adjective <object> = <a1> [a2] [a3]gm2Slots 1–3; omit the value to clear.
@trailer <object> = <text>gm2Slot 4.
@title <object>gm2Rebuild the display name from the current parts.

Action messages

CommandAuthShown to
@success <object> = <msg>gm2The actor, on success.
@osuccess <object> = <msg>gm2Everyone else, on success.
@failure <object> = <msg>gm2The actor, on failure.
@ofailure <object> = <msg>gm2Everyone else, on failure.
@drop <object> = <msg>gm2The actor, on drop.
@odrop <object> = <msg>gm2Everyone else, on drop.

These accept substitution tokens — %S, %d and the rest. +pron prints the full table.

Properties and tags

CommandAuthDoes
@set <object>.<prop> = <value>gm3Set a property (aliased @val).
@unset <object>.<prop>gm3Clear a value.
@adprop <object>.<prop> [= <value>]gm3Add a new property.
@rmprop <object>.<prop>gm3Remove a property.
@remprop <object>.<prop>gm3Remove an inherited property override.
@clear <object>.<prop|verb>gm3Clear a property or verb.
@adtag <object> = <cat>[/<tag>]gm3Add a tag.
@rmtag <object> = <cat>[/<tag>]gm3Remove a tag.

@set resolves #N to a live object on input. A scalar is stored as "#N" and auto-resolves on read; inside a list or dict it is stored as a plain integer.

Verbs

CommandAuthDoes
@adverb[/hidden] <obj>.<names> [with ...]gm3Create a verb.
@program <obj>.<verb>gm3Open the in-MOO editor (aliased @prog, @code).
@rmverb <obj>.<verb>gm3Delete a verb.
@reload <obj>.<verb> / @reload allgm3Load verb code from disk.
@min <obj>.<verb> = <n>gm3Set abbreviation minimum.
@verbauth <obj>.<verb> [= <n>]gm3View or set required auth level.
@hideverb <obj>.<verb>gm3Make non-invokable from the command line.
@unhideverb <obj>.<verb>gm3Reverse it.

eval <expression>gm3Evaluate Python live (aliased /).

Server and accounts

CommandAuthDoes
@auth <player> = add|remove <level>gm5Grant or revoke authority.
@initchar <target>gm3Initialise a character with default properties.
@delplayer <object#>gm4Delete a player account.
@reserve #<a> to #<b>gm5Reserve object numbers (/free, /list).
@fon / @foffgm3Release / protect your personal number range.
@restart [noapi] [<msg>]gm5Restart the server in place.
@shutdown [<msg>]gm5Stop the server, checkpointing on the way out.
@windupgm2Wind up a tickered object.
Adding your own

Nothing here is privileged engine code. Every command above is a verb file on #3 that begins with an auth_level guard. Adding a staff command is @adverb #3.@mycommand with auth=3 and writing the body — which is the whole point.
